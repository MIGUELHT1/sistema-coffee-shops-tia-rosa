# Como contribuir

Obrigado por se interessar pelo Coffee Shops Tia Rosa!

Este é um projeto de estudos. Sugestões, correções e melhorias são bem-vindas.

## Preparar o ambiente

1. Instale o Python 3.12 ou uma versão compatível.
2. Faça um fork do repositório.
3. Clone seu fork:

   ```bash
   git clone https://github.com/SEU-USUARIO/sistema-coffee-shops-tia-rosa.git
   ```

4. Entre na pasta do projeto:

   ```bash
   cd sistema-coffee-shops-tia-rosa
   ```

## Executar a aplicação

```bash
python ATIVIDADEATIVA.py
```

## Executar os testes

Antes de enviar uma alteração, execute:

```bash
python -m unittest discover -v
```

## Enviar uma melhoria

1. Crie uma branch com um nome simples, como `feat/nova-funcionalidade` ou `fix/validacao`.
2. Faça uma alteração pequena e objetiva.
3. Execute os testes.
4. Descreva claramente o que mudou no commit.
5. Abra um Pull Request explicando a alteração.

## Boas práticas

- Mantenha o código simples e legível.
- Evite adicionar dependências sem necessidade.
- Atualize a documentação quando o comportamento mudar.
- Inclua testes para novas regras de negócio.
