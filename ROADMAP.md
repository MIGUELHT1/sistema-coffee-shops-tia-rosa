# Roadmap do projeto

Este documento registra ideias de evolução para o Coffee Shops Tia Rosa. As melhorias serão implementadas gradualmente, conforme o aprendizado e a disponibilidade.

## Concluído

- [x] Separação do código em módulos.
- [x] Cadastro de clientes e produtos.
- [x] Criação e consulta de pedidos.
- [x] Validação básica de entradas.
- [x] Testes unitários iniciais com `unittest`.
- [x] Execução automática dos testes com GitHub Actions.

## Próximas melhorias

- [ ] Melhorar as validações de telefone e valores monetários.
- [ ] Permitir remover ou atualizar clientes e produtos.
- [ ] Adicionar identificadores aos pedidos.
- [ ] Persistir os dados em SQLite.
- [ ] Ampliar a cobertura dos testes.
- [ ] Separar regras de negócio da interface de terminal.

## Ideias futuras

- [ ] Criar uma API REST para o sistema.
- [ ] Desenvolver uma interface web.
- [ ] Avaliar uma migração de aprendizado para Java e Spring Boot.

> O roadmap é um planejamento aberto. As funcionalidades marcadas como pendentes ainda não fazem parte da aplicação.
